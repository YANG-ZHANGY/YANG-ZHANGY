## 關於我

我目前在<strong>香港都會大學</strong>攻讀政治與公共行政哲學碩士（MPhil），並已取得<strong>塔爾圖大學</strong>政治與治理碩士（MA）學位。

我的研究興趣涵蓋<strong>比較政治與國際政治經濟學</strong>，包括政治制度、威權治理、中國政治經濟及台灣政治行為。這個 GitHub 整理公開研究程式、重現說明與方法資源。

## 精選公開研究

### When Conflict Leaves the Rules

<strong>Party Institutionalisation, System Closure and Legislative Violence in Europe</strong>

議會內的政治競爭在什麼條件下演變為肢體暴力？這項研究以歐洲議會為對象，分析政黨制度化、政黨體系封閉性與極化。

<strong>已刊於 The Journal of Legislative Studies</strong> · <strong>重現資料包 2.0 版</strong> · <strong>Python 與 R</strong>

[閱讀期刊論文](https://doi.org/10.1080/13572334.2026.2708491) · [取得完整資料包](https://dataverse.harvard.edu/dataset.xhtml?persistentId=doi:10.7910/DVN/B2ZUV8&version=2.0) · [瀏覽重現程式](https://github.com/YANG-ZHANGY/YANGResearch/tree/main/published-research/legislative-violence-replication)

程式庫附有面板資料分析流程、變數定義、資料來源與 Hybrid Poisson 重建的限制說明。完整套件以 Dataverse 的版本化存檔為準。

## 方法與工具

<strong>研究方法：</strong>面板分析、固定效果模型、事件層級診斷、調查分析、網絡暴露指標與計算文本分析。

<strong>軟體工具：</strong>R、Python、Stata、Jupyter、LaTeX、GitHub、Claude Code、Codex。

我以變數說明、程式與方法筆記，以及資料版本記錄，讓讀者能追溯分析選擇與研究結果。
